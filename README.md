# samjmerrick.com

Personal site and CV for Sam Merrick. Plain static HTML/CSS/JS, no build step.

- `index.html` — content
- `styles.css` — styles (light and dark themes, print stylesheet)
- `ridges.js` — the animated fingerprint ridge map in the hero
- `favicon.svg`

Preview locally:

    python3 -m http.server 8000

Deployed with GitHub Pages at samjmerrick.com (see `CNAME`).
